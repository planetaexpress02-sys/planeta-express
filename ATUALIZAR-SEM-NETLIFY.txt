OPÇÃO 3 — SITE ONLINE GRÁTIS, SEM CRÉDITOS: GITHUB PAGES  (recomendado)
------------------------------------------------------------------------
O seu projeto já está no GitHub (é de lá que o Netlify puxava). O GitHub
tem um serviço de site GRÁTIS e SEM LIMITE de créditos, chamado GitHub Pages.
Configura UMA vez e, depois, cada "Push" já atualiza o site sozinho.

PASSO A PASSO (uma vez só):
1. No GitHub Desktop, clique em "Push origin" para enviar a versão v5.5.
2. Abra o navegador em: https://github.com   (faça login).
3. Entre no seu repositório (o projeto Planeta Express).
4. Clique na aba "Settings" (Configurações) do repositório.
5. No menu da esquerda, clique em "Pages".
6. Em "Build and deployment" > "Source", escolha "Deploy from a branch".
7. Em "Branch", escolha "main" e a pasta "/ (root)". Clique em "Save".
8. Espere 1 a 2 minutos e recarregue a página. O GitHub vai mostrar o
   endereço do seu site, algo como:
      https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/
9. Esse é o seu novo site online. Salve/favorite esse link.

DEPOIS DISSO: sempre que eu fizer uma melhoria, você só dá "Push origin"
no GitHub Desktop e o GitHub Pages atualiza o site sozinho (grátis).

Obs.: o login/sincronização (Supabase) funciona igual no GitHub Pages.
